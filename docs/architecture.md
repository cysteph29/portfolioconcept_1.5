# Architecture

This repository is a Next.js App Router project for a product design portfolio.

## Current Phase

Step 1 scaffolding only:

- baseline app runtime
- project structure
- tooling
- content schema contracts

Homepage sections and visual composition are intentionally deferred.

## Directory Structure

- `app`: routes, layouts, and global styles
- `src/components`: reusable UI components (to be added later)
- `src/content`: MDX source content for projects/pages
- `src/lib`: shared utilities and content parsing logic
- `docs`: technical decisions and planning artifacts
- `public`: static assets

## Runtime

- Framework: Next.js App Router
- Language: TypeScript
- Package manager: npm
- Deployment target: Vercel
